\# AYNAI



\### Intelligent Network Monitoring \& Edge Anomaly Detection



AYNAI is a modular Python project for network service monitoring,

performance measurement, and future edge-based anomaly detection.



\## Current Status



Phase 1 — HTTP Monitoring Core



Implemented:

\- HTTP service availability checks

\- HTTP status code collection

\- Response-time measurement

\- Timeout and connection error handling

\- Monitoring multiple services

\- Automated unit tests



\## Run Locally



Requirements: Python 3.14 or compatible.
